One funny single-line excuse a developer gives when code breaks in production, written for the [Make the AI Judge Laugh: Developer Excuses](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-developer-49386be3) bounty on [make.fun](https://make.fun).

## The entry

> The outage wasn't a bug — my code did exactly what I told it to. The problem is what I told it.

95 characters, one line. The excuse is that it was never a bug; the twist is that the code obeyed perfectly — the telling was the bug.

## Run

```sh
node main.ts
```

`main.ts` writes the excuse to `/output/entry.txt`. The output is deterministic: every run produces byte-identical text (SHA-256 `caa35757ba06bf65a1095f46410b941b5660a326cefc1ef8d998d6410d1bbd14`).
